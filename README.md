# Project Service
***
### Основная информация
Сервис реализует функционал управления проектами пользователей. 
Проекты добавляются из различных источников: Telegram Mini App, команды Telegram бота (/addproject) и импорта из Google таблиц.

### Используемый стек
- Spring Boot 3
- Spring Data JDBC
- Spring Kafka
- Liquibase
